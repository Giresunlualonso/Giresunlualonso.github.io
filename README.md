# F1 Telemetri

Formula 1 yarışlarını veriyle takip eden gayriresmi hayran sitesi: sezon puan durumu, yarış sonuçları, tur süreleri,
lastik stratejisi, sıralama, enerji yönetimi tahmini, haberler ve takvim.

Veri: [OpenF1](https://openf1.org) ve [Jolpica F1](https://github.com/jolpica/jolpica-f1).
Pilot ve araç fotoğrafları Wikimedia Commons'tan (serbest lisanslı); atıflar ilgili sayfalarda.
Bayraklar: [flag-icons](https://github.com/lipis/flag-icons) (MIT).

Resmi Formula 1 sitesi değildir; Formula 1 ile bağlantısı yoktur. Mağaza bölümü denemedir, satış yapılmaz.
